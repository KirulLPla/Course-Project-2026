# Course-Project-2026
## Тема работы: Система мониторинга расхода продукта
## Постановка задачи:
### Программа предназанчена для мониторинга процесса в реакторе по параметру "Расход продукта" (X). Программа также производит преобразования показаний Q(X), производит контроль и анализ.
## Входные данные:
* Параметр X: расход продукта, измеряется в л/мин
* Диапазон X: от 5 до 70 л/мин
* Штатный режим: 25-48 л/мин (значения вне диапазона рассматриваются как отклонение)
* Количество измерений N: 70 
## Формула преобразования Q(X):


$$Q(X) =
\begin{cases} 
2 * (X - 25) + 10, &\text{если } X < 25\\
(X-36.5)^2/7+45, &\text{если } 25 \le X  \le 48\\
3 \ sqrt{X-48+1} + 55, &\text{если } X > 48
\end{cases}$$
