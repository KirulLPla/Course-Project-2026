# Course-Project-2026

## Тема работы: Система мониторинга расхода продукта

## Постановка задачи
Программа предназначена для мониторинга процесса в химическом реакторе по технологическому параметру «Расход продукта» ($X$). Программа производит кусочное преобразование показаний в показатель $Q(X)$, выполняет оперативный контроль отклонений и статистический анализ.

## Входные данные
* **Параметр $X$:** расход продукта, измеряется в л/мин.
* **Диапазон измерений $X$:** от 5 до 70 л/мин.
* **Штатный режим:** 25–48 л/мин (значения вне диапазона рассматриваются как отклонение).
* **Количество измерений $N$:** 70.

## Формула преобразования $Q(X)$

$$Q(X) =
\begin{cases} 
2 \cdot (X - 25) + 10, &\quad\text{если } X < 25\\
\frac{(X - 36.5)^2}{7} + 45, &\quad\text{если } 25 \le X \le 48\\
3\sqrt{X - 48 + 1} + 55, &\quad\text{если } X > 48
\end{cases}$$

**Область определения:** $X \in [5; 70]$ л/мин.  
**Физический комментарий к граничным режимам:** При снижении расхода ниже штатного уровня ($X < 25$ л/мин) расчетный показатель принимает значения $Q < 10$ (вплоть до $Q = -30$ при минимальном расходе $X = 5$ л/мин). В контексте технологического процесса реактора такое падение интерпретируется как критическое прекращение подачи сырья и аварийное состояние, требующее немедленной сигнализации.

## Ручной расчет (проверочные примеры)
* **$X = 20$** ($X < 25$):  
  $$Q(20) = 2 \cdot (20 - 25) + 10 = -10 + 10 = 0.00$$
* **$X = 30$** ($25 \le X \le 48$):  
  $$Q(30) = \frac{(30 - 36.5)^2}{7} + 45 = \frac{42.25}{7} + 45 \approx 6.04 + 45 = 51.04$$
* **$X = 60$** ($X > 48$):  
  $$Q(60) = 3\sqrt{60 - 48 + 1} + 55 = 3\sqrt{13} + 55 \approx 3 \cdot 3.60555 + 55 = 65.82$$

## Блок-схема алгоритма
Схема отражает полный цикл: ввод параметра $X \to$ расчет функции $f(X) \to$ получение $Q \to$ проверка условия контроля $|Q - Q_0| \le \Delta Q_{\max} \to$ определение и вывод состояния (`STATE`).
